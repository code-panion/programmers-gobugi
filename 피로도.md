# 접근 방식
처음에는 앞에서 돌면서 갈까/말까로 하면 되겠다 라고 생각을 했으나, 이러면 중간에 있는 것들만 달라지는 거라서 수열에서나 통하는 방법이다.

던전이 일직선이 아니니까 순열로 다시 풀어야한다.

# 학습 내용


```java
import java.util.*;

class Solution {
    static int mx = -1;
    public int solution(int k, int[][] dungeons) {
        go(k, 0, 0, dungeons);
        return mx;
    }
    public void go(int k, int cnt, int idx, int[][] dg){
        if(idx == dg.length || k < dg[idx][0]){
            // 수행을 못할 경우 지금까지 방문한 거 더하기
            mx = Math.max(cnt, mx);
            return;
        }
        // idx번째 던전을 갈지, 안갈지
        go(k-dg[idx][1],cnt+1, idx+1, dg); // 가
        go(k,cnt, idx+1, dg); // 안가
    }
}
```

이건 수열에서나 통할 것

```java
public void dfs(int k, int cnt, int[][] dungeons) {
    mx = Math.max(mx, cnt);

    for (int i = 0; i < dungeons.length; i++) {
        if (v[i]) continue;
        if (k < dungeons[i][0]) continue;

        v[i] = true;
        dfs(k - dungeons[i][1], cnt + 1, dungeons);
        v[i] = false;
    }
}
```
이렇게 하면, 순열이 완성된다. 내가한건 어떻게 보면 순서 상관없이 뽑는 조합에 가까움

# 풀이 코드 
```java
import java.util.*;

class Solution {
    static int mx = -1;
    static boolean[] v;
    
    public int solution(int k, int[][] dungeons) {
        v = new boolean[dungeons.length];
        // go(k, 0, 0, dungeons);
        dfs(k, 0, dungeons);
        
        return mx;
    }
    
    public void dfs(int k, int cnt, int[][] dungeons) {
        mx = Math.max(mx, cnt);

        for (int i = 0; i < dungeons.length; i++) {
            if (v[i]) continue;
            if (k < dungeons[i][0]) continue;

            v[i] = true;
            dfs(k - dungeons[i][1], cnt + 1, dungeons);
            v[i] = false;
        }
    }
    
    public void go(int k, int cnt, int idx, int[][] dg){
        if(idx == dg.length || k < dg[idx][0]){
            mx = Math.max(cnt, mx);
            return;
        }
        // idx번째 던전을 갈지, 안갈지
        go(k-dg[idx][1],cnt+1, idx+1, dg); // 가
        go(k,cnt, idx+1, dg); // 안가
    }
}
```

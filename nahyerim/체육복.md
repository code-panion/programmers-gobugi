# 접근 방식
일단 여벌 체육복을 가진 학생들 중 번호가 작은 순부터 우선 소비되도록 했다. 오름차순 순회라 다음에 큰 번호의 아이가 체육복을 도둑맞았을 수도 있기 때문이다. 그래서 체육복이 없다면 없는 아이 앞번을 먼저 확인하고 그 다음 뒷번호가 여벌 체육복이 있는지 확인하도록 했다. 

</br>
</br>

# 학습내용
분명 멀쩡하게 짠 거 같은데 왜 66.7점이라고 3분의 2만 맞출까 고민했는데, 여벌 체육복을 가진 아이가 체육복을 도둑 맞을 수 있단 대목을 대충 봐서 
answer 초기값을 n - len(lost)로 설정해놨기 때문이었다. 고치니 잘됨. 

</br>
</br>

# 풀이 코드

```
def solution(n, lost, reserve):
    answer = 0
    student = [1] * (n+1)
    for i in range(len(lost)):
        student[lost[i]] -= 1
    
    for j in range(len(reserve)):
        student[reserve[j]] += 1
    #print(student)
    for k in range(1, n+1):
        if not student[k] and k > 1:
            if student[k-1] > 1:
                answer += 1
                student[k-1] -= 1
            elif n >= k + 1 and student[k+1] > 1:
                answer += 1
                student[k+1] -= 1
        elif not student[k] and k == 1:
            if student[2] > 1:
                answer += 1
                student[2] -= 1  
        else:
            answer += 1
            
    return answer
```

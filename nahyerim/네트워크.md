# 학습내용
오랜만에 푸니까 직접적으로 연결되는 노드만 탐색하는 불완전한 dfs 를 만들었는데 dfs 생성 방식을 다시 찾아보고 구현함. 예외처리를 하거나 알고리즘 로직을 찬찬히 생각하는 게 아직 부족한 것 같음.

# 풀이 코드

### 개선 코드 
```
def solution(n, computers):
    visited = [0] * n
    answer = 0

    for i in range(n):
        if not visited[i]:
            answer += 1
            stack = []
            visited[i] = 1
            stack.append(i)
            while stack:
                cur = stack.pop(0)
                for j in range(n):
                    if computers[cur][j] and not visited[j]:
                        visited[j] = 1
                        stack.append(j)
    return answer
```

### 불완전 했던 코드 
```
def solution(n, computers):
    answer = 0
    check = [0] * n
    s = 0
    for i in range(n):
        # 새로운 네트워크라면
        if not check[i]:
            # 1 더하고 방문체크 
            s += 1
            check[i] = s
        # 새로운 네트워크보다 큰 노드들을 순회하기(그 보다 작은 노드는 이미 순회했거나 같은 네트워크일테니까)
        for j in range(i+1, n):
            # 다른 노드인데 연결돼있고 아직 체크되지 않은 노드라면
            if computers[i][j] and not check[j]:
                # 같은 값
                check[j] = s
    print(check)             
    answer = max(check)            
    return answer
```

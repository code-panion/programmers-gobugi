# 접근 방식
우선 순위 큐이기 때문에 현재 나온 값이 남은 배열의 최고값과 같거나 작다면 실행하고, 실행되고 나면 rate가 1씩 증가하도록 했다.

</br>

# 학습내용
아래 코드에서는 자꾸 테스트 케이스가 40점 정도만 맞아서 어째서 그런지 한참 고민했는데, 질문 게시판의 [1,2,3,4,5], 2 의 결과값이 3이라는 예외케이스를 
적용해보라는 걸 보고 해보니 문제를 깨닫게 됨. 난 i 값을 계속 더하면서 길이만큼 나눠주면 계속 i 값이 유지된다고 생각했는데 사실 계속 같은 길이로 유지되는
배열이 아니기 때문에 값이 틀리게 되는 거였다. 그래서 값을 지우는 대신 0으로 변경하는 방식으로 배열을 유지시켰고, 식도 더 간략하게 바꿨다.

# 풀이 코드

### 올바른 코드 
```
def solution(priorities, location):
    answer = 0
    que = []
    rate = 1
    for i in range(len(priorities)):
        que.append((i, priorities[i]))
    while que:
        idx, num = que.pop(0)
        #print(idx, num)
        if max(priorities) <= num:
            # max()를 이용하되 현재 사용한 인덱스 값은 더이상 최고값이 되지 않도록 해당 요소값을 변경시킴 
            priorities[idx] = 0
            if idx == location:
                answer =rate
                break
            rate += 1
        else:
            que.append((idx, num))
                  
    return answer
```

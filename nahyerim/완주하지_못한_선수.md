# 접근 방식
초반엔 별 생각없이 for문 두개를 돌렸는데 시간 초과가 나면서 숫자범위가 너무 크다는 사실을 깨달았다. 그래서 해시 태그에 맞춰 딕셔너리 형태로 구현하니 해결할 수 있었다. 


</br>
</br>

# 학습내용
시간 복잡도에 있어서 for문 두개는 O(N²) 이고 딕셔너리로 구현하면 O(N)의 복잡도로 구현된다는 사실을 다시 한번 깨달았다. 

</br>
</br>

# 풀이 코드

```
def solution(participant, completion):
    dicP = {}
    dicC = {}
    answer = ''
    for p in participant:
        dicP[p] = 0
    for p in range(len(participant)):
        if participant[p] in dicP.keys():
            dicP[participant[p]] += 1
    for c in completion:
        if c in dicP.keys():
            dicP[c] -= 1
    
    for p in dicP.keys():
        if dicP[p]:
            answer = p
    
    return answer 
```

챗지에게 물어 더 계선된 해시맵 형태의 코드로 구현하자면 
```
def solution(participant, completion):
    hashmap = {}
    for name in participant:
        hashmap[name] = hashmap.get(name, 0) + 1
    for name in completion:
        hashmap[name] -= 1
    for name in hashmap:
        if hashmap[name] != 0:
            return name
```
이렇게 구현할 수 있다고 하고 이러면 상수 계수가 4N에서 3N 이내로 줄어들어서 더 효율적이란다... 아직 와닿진 않음

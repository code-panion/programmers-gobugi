# 접근 방식
패턴 기준으로 나눠서 값을 구하도록 구현했다. 

</br>
</br>

# 학습내용
처음엔 제일 긴 패턴이 student3으로 배열을 10개 요소를 가진 배열들로 다 고정시켜서 돌렸는데 이렇게 하니 틀리게 나왔다. 그 이유는 패턴 길이가 각각 
다르기 때문에 조건과 다르게 돌아가기 때문이었다. 기본적인 부분을 실수하지 않도록 노력해야겠다. 각 학생의 찍기 패턴 길이에 맞게 모듈로 연산을 적용해 수정하니 옳게 계산됐다. 

</br>
</br>

# 풀이 코드

```
def solution(answers):
    answer = []
    student1 = [1, 2, 3, 4, 5]
    student2 = [2, 1, 2, 3, 2, 4, 2, 5]
    student3 = [3, 3, 1, 1, 2, 2, 4, 4, 5, 5]
    cnt = [0] * 4
    for i in range(len(answers)):
        if student1[i%5] == answers[i]:
            cnt[1] += 1
        if student2[i%8] == answers[i]:
            cnt[2] += 1
        if student3[i%10] == answers[i]:
            cnt[3] += 1
    print(cnt)
    max_a = max(cnt)
    for i in range(1, 4):
        if max_a == cnt[i]:
            answer.append(i)
    return answer
```

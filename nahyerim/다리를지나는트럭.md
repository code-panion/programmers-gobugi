# 학습내용
 아래 코드로 풀었는데 que에 집어넣을때 해당 트럭이 완전히 도착한 시점을 계산해서 넣으려고 한게 문제인 것 같다. 이렇게 되니 중간중간에 
 해당 트럭이 도착한 시작대에 출발하는 다른 트럭들의 계산이 꼬인 듯. 잘 쓴 풀이가 있어서 보고 제대로 익혀야겠다고 생각함.

# 풀이 코드

### 올바른 코드 
```
from collections import deque

def solution(bridge_length, weight, truck_weights):
    answer = 0
    bridge = deque([0] * bridge_length)
    truck_weights = deque(truck_weights)
    total_weight = 0

    while bridge:
        answer += 1
        total_weight -= bridge.popleft()

        if truck_weights:
            if total_weight + truck_weights[0] <= weight:
                t = truck_weights.popleft()
                bridge.append(t)
                total_weight += t
            else:
                bridge.append(0)  # 무게 넘으면 weight가 0인 트럭이 간다고 생각하고 채움

    return answer
```

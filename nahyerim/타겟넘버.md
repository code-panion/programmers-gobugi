# 접근 방식
DFS나 BFS 방식을 생각해서 que 형식이나 재귀로 풀려고 했는데 뭔가 풀리지 않음... 자꾸 2개 케이스 시간 초과. 그래서 고민하다가 +,- 는 이진수로 표현가능하다는 생각에 이진수를 응용하는 방식으로 적용하였고 풀이 성공함. 예를 들어 숫자가 [1,1,1,1,1] 이렇게 있는 경우에는 +, - 로 계산할수 있는 경우의 수가 총 32가지이기 때문에 32까지의 이진수 목록을 만듦. 00000,00001,00010... 그런 다음 리스트의 숫자들을 이진수의 자리수에 대응하여 0일 때는 빼고 1일 때는 더하는 식으로 구현하였고 이러한 계산 합이 target이 된다면 answer 가 증가하도록 함. 

</br>
</br>

# 학습내용
format(정수, 'b')를 사용하면 b를 뗀 형태로 이진수를 받아올 수 있어서 이 포맷을 이용해서 이진수로 변환한 뒤, 부족한 자릿수는 앞에 추가하는 방식으로 구현함.  

</br>
</br>

# 풀이 코드

```
def solution(numbers, target):
    answer = 0
    # 경우의 수는 정수의 갯수의 2배수 만큼있으므로 변환할 2진수의 범위를 이렇게 정의 
    check = [format(i, 'b') for i in range(0, 2**len(numbers))]
    # 이진수를 numbers의 길이만큼 맞출 수 있도록 문자열로 변환할 리스트 
    strChe = []
    for i in check:
        stI = str(i)
        # 현재 이진수의 길이가 numbers의 길이보다 짧다면 앞에 그만큼 0을 붙여주기 
        if len(stI) < len(numbers):
            stI = '0' * (len(numbers)-len(stI)) + stI
        strChe.append(stI)
    for j in range(len(strChe)):
        num = strChe[j]
        sum_v = 0
        for k in range(len(numbers)):
            if num[k] == '0':
                sum_v -= numbers[k]
            else:
                sum_v += numbers[k]
        if sum_v == target:
            answer += 1
    return answer
```

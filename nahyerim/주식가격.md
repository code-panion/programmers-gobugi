# 접근 방식
인덱스 기준으로 그 다음 값들과 비교해서 값이 계속 같거나 커진다면 시간을 1씩 더하도록 만들었다. 

</br>
</br>

# 학습내용
for 문을 거꾸로 돌릴까 그대로 돌릴까 고민하다가 그대로 돌려도 상관없을 거 같아서 그대로 했다. 

</br>
</br>

# 풀이 코드

```
def solution(prices):
    answer = [0] * len(prices)
    for i in range(len(prices)-1):
        time = 0
        for j in range(i+1, len(prices), 1):
            if prices[i] <= prices[j]:
                time += 1
            # 만약 바로 break 돼도 1초는 유지된거기 때문에 +1 해주기  
            else:
                time += 1
                break
        #print(i, time)
        answer[i] = time
    answer[len(prices)-1] = 0
    return answer
```

# 접근 방식
완전 탐색이라 문자열 조합을 어떤 식으로 경우의 수를 거를지 고민했다. 
</br>
</br>

# 학습내용
초반엔 dec이라는 리스트에 일부 소수를 집어넣고 그것보다 큰 숫자에서는 그보다 작은 소수를 찾아내는 함수를 넣었는데 이게 오히려 비효율적이었다. 
그냥 문자열로 만들어지는 숫자들을 다신 방문하지 않도록 체크해두고, 그 숫자가 소수인지만 확인하는게 훨씬 시간이 빨랐음. dec_check로 숫자 중복확인하지만 
문자열로 숫자를 계속 만들어내는 것도 그렇고, is_dec 함수 자체도 매번 순회해야하니 성능이 떨어짐. 

그래서 개선 코드가 시간 복잡도가 O(n!) 이하 
개선 전 코드가 O(n! × n × log n)

</br>
</br>

# 풀이 코드
개선 후 코드  

```
num_lst = [0]*10000001
answer = 0

# 소수인지 확인하는 함수 
def find_dec(num):
    global num_lst
    global answer 
    if num_lst[int(num)]:
        return
    if int(num) < 2:
        return False
    for n in range(2, int(num)):
        if not int(num) % n:
            return 
    answer += 1
    num_lst[int(num)] = 1
    return 

# 재귀 돌려서 문자열을 숫자로 만드는 조합 찾는 함수 
def solve(idx, num, arr, used):
    if idx == len(arr) + 1:
        return
    find_dec(num)
    for i in range(len(arr)):
        if not used[i]:
            used[i] = used[idx] + 1
            solve(idx+1, num + str(arr[i]), arr, used)
            solve(idx+1, str(arr[i]) + num, arr, used)
            used[i] = 0
    

def solution(numbers):
    global answer 
    used = [0] * len(numbers)
    for i in range(len(numbers)):
        used[i] = 1
        solve(1, str(numbers[i]), numbers, used)
        used[i] = 0
    return answer
```


개선 전 코드 
```
dec = []
answer = 0
dec_check = [0] * 100000001

def find_dec(arr, used):
    s = ''
    max_i = 1
    global answer
    global dec_check 
    while max_i <= len(arr):
        for i in range(len(used)):
            if used[i] == max_i:
                s += str(arr[i])
        max_i +=1 
    if dec_check[int(s)]:
        return 
    #print(s, used)
    for j in range(dec[-1] + 1, int(s) + 1):
        if is_dec(j):
            dec.append(j)
    for i in range(len(dec)):
        if not dec_check[dec[i]] and dec[i] == int(s):
            answer += 1
    dec_check[int(s)] = 1
    return 

def solve(cnt, idx, arr, used):
    #print(idx, arr[idx], used)
    global dec_check
    find_dec(arr, used)
    if cnt == len(arr):
        return
    for i in range(len(arr)):
        if not used[i]:
            used[i] = used[idx] + 1
            solve(cnt+1, i, arr, used)
            used[i] = 0            

def is_dec(num):
    global dec
    flg = True
    for i in range(len(dec)):
        if not num % dec[i]:
            flg = False
            return
    return flg
    

def solution(numbers):
    global answer
    global dec
    dec = [2, 3, 5, 7, 11, 13]
    used = [0] * len(numbers)
    for i in range(len(numbers)):
        used[i] = 1
        solve(1, i, numbers, used)
        used[i] = 0
    #print(dec)
    return answer
```

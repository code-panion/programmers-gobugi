# 접근 방식
최대한 다양한 종류의 포켓몬을 가져가되, 전체 길이의 절반까지만 가져갈 수 있단 점 또한 생각하여 코드를 구현함.

# 풀이 코드

```
def solution(nums):
    check = [0] * 200001
    answer = 0
    for i in range(len(nums)):
        # 해당 번호의 포켓몬을 아직 체크하지 않았으면
        if not check[nums[i]]:
            # 체크하고 
            check[nums[i]] = 1
            # 종류 1 더하기 
            answer += 1
        # 근데 종류가 아주 많아도 절반 이상 가져갈 수 없으므로 그보다 커지면 종료 
        if answer > len(nums) // 2:
            answer = len(nums) // 2  
            break          
```

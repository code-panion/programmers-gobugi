# 접근 방식

정렬된 상태에서 작은 쪽 두 개 가지고 계속 연산 돌리는 방식을 쓰면 될 것 같다.
로직은 정말 단순

# 학습 내용

자바에서 pq는 minHeap이다.
사용은 메서드 5개 + 커스텀 정렬 이렇게만 알고 있으면 될 것 같다.

offerFirst, pollFirst같은 게 있을줄 알았는데 이건 TreeSet, Deque에 있는 것

```java
pq.offer(값);     // 삽입
pq.poll();        // 최소값 제거 후 반환
pq.peek();        // 최소값 조회 (제거 안함)
pq.size();        // 크기
pq.isEmpty();     // 비어있는지 체크

PriorityQueue<Integer> pq = new PriorityQueue<>((a, b) -> {
    if (a < b) return -1; // 오름차순 - 큰게 뒤로
    if (a > b) return 1; // 내림차순 
    return 0;  // 같다고 간주 -> 원래 순서대로
});
```

# 풀이 코드 

```java
import java.util.*;

class Solution {
    public int solution(int[] sv, int k) {        
        PriorityQueue<Integer> pq = new PriorityQueue<>();
        for(int s: sv){
            pq.offer(s);
        } // init
        
        int cnt = 0;
        if(pq.peek() >= k) return 0;
        while(pq.peek() < k && pq.size() > 1){
            int a = pq.poll();
            int b = pq.poll();
            pq.offer(a+b*2);
            cnt++;
        }
        
        if(pq.peek() < k) return -1;
        return cnt;
    }
}
```

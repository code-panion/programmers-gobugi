# 접근 방식
이 친구도 전형 적인 dp.

생각하기에 어렵지않았다. 근데 이제 좌표를 거꾸로 설명해줘서 그거만 조심하면 될 것 같은 문제

# 학습 내용

# 풀이 코드
```java
class Solution {
    public int solution(int m, int n, int[][] puddles) {
        int MOD = 1000000007;
        long[][] dp = new long[n + 1][m + 1];

        // 웅덩이 위치를 -1로 해서 못가게
        for (int[] puddle : puddles) {
            dp[puddle[1]][puddle[0]] = -1;
        }

        dp[1][1] = 1;

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                // 현재 위치가 웅덩이라면 건너뛰기
                if (dp[i][j] == -1) {
                    dp[i][j] = 0;
                    continue;
                }

                // 위쪽에서 오는 경로 더하기
                if (i > 1) {
                    dp[i][j] += dp[i - 1][j] % MOD;
                }

                // 왼쪽에서 오는 경로 더하기
                if (j > 1) {
                    dp[i][j] += dp[i][j - 1] % MOD;
                }
            }
        }

        return (int) (dp[n][m] % MOD);
    }
}
```

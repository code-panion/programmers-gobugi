# 접근 방식
처음에는 문제를 잘못 이해해서 정렬해서 맨 뒤 부터 문자열 이어붙이기를 했다.
그러니까 2, 6, 10 -> 1062라서 완전 틀린 답이 나왔다.

두번째 접근은 앞에서 부터 문자열을 붙이는데, 앞에다 붙이는 게 큰 지, 뒤에다 붙이는 게 큰 지 비교하면서 넣는 것이었다. 이거 역시 틀린 답을 도출한다.
정렬을 먼저 해서 작은 수 부터 붙이는 방법도 생각해봤는데, 문제의 분류가 정렬인데 그리디처럼 풀어서는 안될 것 같았다. 근데 일단 도전.



# 학습 내용

```java
import java.util.*;

class Solution {
    public String solution(int[] numbers) {
        ArrayList<String> str = new ArrayList();
        for(int i: numbers){
            str.add(String.valueOf(i));
        }
        Collections.sort(str, new Comparator<String>((o1, o2) -> {
            return o1+o2 - o2+o1;
        }));
        
        if(str.get(0).equals("0")) return "0";
        
        StringBuilder ans = new StringBuilder();
        for(String s : str) {
            ans.append(s);
        }
        
        return ans.toString();
    }
}
```
처음에 접근을 이렇게 했음. 근데 아주 중요한 문제가, 문자열은 +로 더할 순 있지만 -로 뺄 수 없다는 점이었고, compareTo()를 써야 했다.

```java
Collections.sort(str, (o1, o2) -> (o2 + o1).compareTo(o1 + o2));
Collections.sort(str, new Comparator<String>() {
    public int compare(String o1, String o2) {
        return (o2 + o1).compareTo(o1 + o2);
    }
});
```
이렇게 해줘야 문자열 간 비교가 가능하다. 기존 Comparator를 써서 -1, 0, 1 으로 하려면 불가능함.
return 문을 좀 더 살펴보면, 이는 BA > AB인지 확인하는 것이다.
BA > AB이면 B가 A보다 앞에 와야 하고, AB > BA이면 A가 B보다 앞에 와야한다.
compareTo 기준 수신객체로 있는 대상이 크면 o2, 수신객체로 있는 대상이 작으면 o1이 먼저 오는 정렬이 된다.

# 풀이 코드 
```java
import java.util.*;

class Solution {
    public String solution(int[] numbers) {
        ArrayList<String> str = new ArrayList();
        for(int i: numbers){
            str.add(String.valueOf(i));
        }
        Collections.sort(str, new Comparator<String>(){
            public int compare(String o1, String o2){
                return (o2+o1).compareTo(o1+o2);
            }
        });
        
        if(str.get(0).equals("0")) return "0";
        
        StringBuilder ans = new StringBuilder();
        for(String s : str) {
            ans.append(s);
        }
        
        return ans.toString();
    }
}
```

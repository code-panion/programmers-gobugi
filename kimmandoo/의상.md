# 접근 방식
hashMap을 이용하는 방법을 배우는 문제

# 학습 내용

의상 별로 배열 만들어서 다 곱하는 방법을 사용해도 되지만, hashMap을 써보자.

```java
map.put("apple", 1); // 값 추가
int bananaCount = map.get("banana"); // 근데 문제는 get했을 때 없으면 null을 반환
map.put("cherry", map.getOrDefault("cherry", 0) + 1); // 그래서 getOrDefault로 null뜨면 기본값 가져오게 하는 것
map.remove("banana"); // "banana"와 값 2가 삭제됨(key, value 동시삭제)
map.containsKey(key) // 특정 Key가 존재하는지 확인 (true/false 반환)

for (String key : map.keySet()) { // 키만 순회할 때
    System.out.println("과일 종류: " + key + ", 개수: " + map.get(key));
}

int totalCount = 0;

for (int count : map.values()) { // value만 필요할 떄
    totalCount += count;
}

for (Map.Entry<String, Integer> entry : map.entrySet()) { // keyValue 모두 필요할 때 -> Map.Entry와 entrySet을 기억하자
    String key = entry.getKey(); // entry 객체에 대해 getKey, getValue
    Integer value = entry.getValue();
    System.out.println("과일 종류: " + key + ", 개수: " + value);
}
```

# 풀이 코드 
```java
import java.util.*;

class Solution {
    public int solution(String[][] clothes) {
        int answer = 1;
        HashMap<String, Integer> hm = new HashMap();
        for(String[] p: clothes){
            hm.put(p[1], hm.getOrDefault(p[1],0)+1);
        } // 없으면 0넣고 1더하기 -> NPE 방지
        
        for(Map.Entry<String, Integer> entry: hm.entrySet()){
            answer *= (entry.getValue()+1);
        }
        
        return answer-1; // 공집합은 없다
    }
}
```

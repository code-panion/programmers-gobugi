# 접근 방식
정렬조건을 여러개 만들어서 쓰는 pq 문제인 걸 파악했다.
그래서 우선순위를 먼저 잡아 소요시간이 짧은 순 -> 요청 시각이 빠른 순 -> 번호가 작은 순으로 정렬 순서를 잡았다. 그래서 나온 게 아래코드

```java
PriorityQueue<Disk> pq = new PriorityQueue<>((o1, o2) ->{
    if(o1.time < o2.time){
        // 소요시간이 짧고
        return -1;
    }
    if(o1.elp < o2.elp){
        return -1;
    }
    if(o1.num < o2.num){
        return -1;
    }
    return 0;
});
```

근데 문제 이해를 잘못했다.

# 학습 내용

내 기존 로직은 모든 job을 한꺼번에 넣고, 요청 시점과 관계없이 poll()해서 처리하려고 한 건데 나중에 도착한 job도 미리 큐에 들어간다. 
이러면 큐에서 조건 안 맞는 경우 아무 것도 안 하고 시간만 증가한다. 원래 큐에서 조건이 안맞으면 일단 대기큐에 넣어서 처리해야된다.

그리고 작업 종료 시간 - 요청 시간의 평균을 알려달라고 했으므로 내 방식대로 하면 무조건 틀린다.

접근을 다시해야된다.

1. 시간순 정렬된 대기 리스트 유지
2. 현재 시간 기준으로, 큐에 들어올 수 있는 job들을 SJF 우선순위로 넣음
3. 처리 가능한 job이 없다면 → 시간 증가
4. 처리 가능한 job이 있다면:
    1. 우선순위 높은 job 선택
    2. 현재 시간 += 작업 시간 
    3. (현재 시간 - 요청 시간)을 결과에 더함

그래서 로직을 새로 짜야한다.

아직 커스텀 정렬 기준을 설정하는 게 너무 미숙하다. 이 문제는 두 세번 더 풀어야함

# 풀이 코드
```java
import java.util.*;

class Solution {
    public int solution(int[][] jobs) {
        boolean[] inserted = new boolean[jobs.length]; // jobs가 큐에 들어갔는지 표시
        PriorityQueue<Disk> pq = new PriorityQueue<>((a, b) -> a.elp - b.elp);
        // 작업 소요시간이 작은 순서대로 정렬되는 minHeap
        int now = 0; // 현재 시간
        int sum = 0;
        int done = 0;

        while (done < jobs.length) {
            // 현재 시간에 들어올 수 있는 job을 모두 우선순위 큐에 넣는다
            // 현재시간에 가능한 job을 넣는 게 중요
            for (int i = 0; i < jobs.length; i++) {
                if (!inserted[i] && jobs[i][0] <= now) { // 큐에 들어가있지않고, 요청 시각이 현재 시간보다 작은 걸 다 넣는다.
                    pq.offer(new Disk(i, jobs[i][0], jobs[i][1]));
                    inserted[i] = true;
                }
            }

            // 여기서는 pq가 이미 시간안에 끝낼 수 있는 작업만 들고 있다.
            if (!pq.isEmpty()) {
                Disk job = pq.poll();
                now += job.elp;
                sum += (now - job.time);
                done++;
            } else {
                now++; // 처리 가능한 job이 없으면 시간만 흐름
            }
        }

        return sum / jobs.length;
    }
}

class Disk {
    int num, time, elp;
    Disk(int n, int t, int e) {
        num = n;
        time = t;
        elp = e;
    }
}

```

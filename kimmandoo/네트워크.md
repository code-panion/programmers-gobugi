# 학습 내용

이 문제는 인접행렬이라 그래프 문제로 접근하는 게 맞다.
노드를 이어서 체크하는 방식으로 해야된다. 즉 bfs는 bfs지만 노드 bfs...

```java
public void bfs(int start, int[][] computers) {
    Queue<Integer> q = new LinkedList<>();
    q.offer(start);
    visited[start] = true;

    while (!q.isEmpty()) {
        int cur = q.poll();
        for (int i = 0; i < computers.length; i++) {
            if (computers[cur][i] == 1 && !visited[i]) {
                visited[i] = true;
                q.offer(i);
            }
        }
    }
}
```

이렇게 하면, 노드를 돌면서 인접한 노드 중 방문하지 않은 걸 큐에 넣고, 더 이어질 때 까지 (큐가 비워질때까지) 방문처리를 수행한다..

예전부터 인접행렬에 대한 처리를 좀 헷갈려했는데 이번 기회에 정리를 좀 해야겠다.


# 풀이 코드 

```java
import java.util.*;

class Solution {
    static boolean[] visited;
    static int cnt = 0;
    public int solution(int n, int[][] computers) {
        visited = new boolean[n];

        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                bfs(i, computers);
                cnt++;
            }
        }

        return cnt;
    }

    public void bfs(int start, int[][] computers) {
        Queue<Integer> q = new LinkedList<>();
        q.offer(start);
        visited[start] = true;

        while (!q.isEmpty()) {
            int cur = q.poll();
            for (int i = 0; i < computers.length; i++) {
                if (computers[cur][i] == 1 && !visited[i]) {
                    visited[i] = true;
                    q.offer(i);
                }
            }
        }
    }
}
```

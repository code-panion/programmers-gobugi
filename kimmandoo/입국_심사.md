# 접근 방식
n명이 줄을 서 있다. 한 심사대에는 한 명 씩 처리. 더 빨리 끝나는 곳이 있으면 거기 먼저. 
모든 사람이 심사를 받는 데 걸리는 최소 시간을 구해야 됨. 처음에는 "최소를 최대로"같은 이분 탐색 유형 부분을 못 찾았다.

근데 시간을 기준으로 보면, 가능한 시간이 제일 작게 -> 이게 딱 이분탐색이었다.

중요한 건 어떻게 시간처리를 할지다.

생각을 해보면, 가장 오래걸리는 심사관기준으로 loop 수 만큼 곱하면 최대 시간이 나올거고, 각 심사관은 그 시간에서 심사관 배치시간만큼 나눈 몫만큼 처리량을 갖고있다.
이거만 관찰해서 알았다면 끝

# 학습 내용

처음에 문제를 잘못읽어서 r 초기화 값을 10억으로 했는데, 한 명당 최대 10억이니 무조건 10억이 넘는다는 점을 간과했다.
그리고 이분탐색은 정렬이 기본이다.

# 풀이 코드 
```java
import java.util.*;

class Solution {
    public boolean go(int n, long m, int[] t){
        // m 시간이면 다 돌 수 있는 지?
        long sum = 0;
        for (int i = 0; i < t.length; i++) {
            sum += m / t[i]; // i번째 심사관이 m 시간 동안 처리할 수 있는 인원
            if (sum >= n) return true; // 이미 n명 이상이면 더 계산할 필요 없음
        }
        return false;
    }
    public long solution(int n, int[] times) {
        // n 명이 줄 서 있음.
        Arrays.sort(times); // 심사관 오름차순 정렬
        long l = 1L;
        long r = (long) times[times.length - 1] * n;
        long answer = r;
        while(l<=r){
            long m = (l+r)/2;
            if(go(n, m, times)){
                answer = m;
                // 조건을 만족하면 더 작은 시간으로
                r = m - 1;
            }else{
                l = m + 1; 
            }
        }
        
        return answer;
    }
}
```

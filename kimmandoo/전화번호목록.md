# 접근 방식
분류가 Hash지만 따로 아이디어가 떠오르지 않아서 string 메서드 썼다.

예상대로 시초... 효율성 검사에서 통과하지 못했다.

# 학습 내용

```java
import java.util.*;

class Solution {
    public boolean solution(String[] pb) {
        boolean answer = true;
        // 어떤 번호가 다른 번호의 접두어면 false
        for(int i=0; i<pb.length; i++){
            for(int j=0; j<pb.length; j++){
                if(i==j) continue;
                if(pb[i].startsWith(pb[j])) return false; 
            }
        }
        return answer;
    }
}
```

이렇게 하면 O(n^2)이라 길이가 100만이면 터져버린다.

EntrySet같은걸 써야하나 했더니, 그냥 substring 한칸씩 늘려가면서 set에 들어있나 확인하는 문제였다.
이렇게 하면 n*n이 아니라, n*L(문자열 길이)이 돼서 시간초과 없이 통과할 수 있따.

# 풀이 코드 

```java
import java.util.*;

class Solution {
    public boolean solution(String[] pb) {
        boolean answer = true;
        Set<String> set = new HashSet<>();

        for (String num : pb) {
            set.add(num);
        }

        for (String num : pb) {
            for (int i = 1; i < num.length(); i++) {
                String prefix = num.substring(0, i);
                if (set.contains(prefix)) {
                    return false;
                }
            }
        }
        return answer;
    }
}
```

# 접근 방식
문제 설명이 너무 장황했다.
주어진 포켓몬 리스트의 절반만 가져갈 수 있는데, 그 때 최대 종류를 반환하는 로직을 짜야한다.
그래서 중복되는 걸 제거하려고 HashSet으로 처리해 일단 담고, 뽑아야하는 마리 수 보다 작으면 set 크기, 크거나 같으면 뽑아야하는 개수인 n/2를 반환하면 된다.

# 학습 내용
h-index문제도 그렇고, 이 문제도 그렇고 설명을 길게해서 핵심을 흐리는 방법으로 유도한다고 느꼈다. 문제의 핵심만 정리해서 접근해야된다.

# 풀이 코드 
```java
import java.util.*;

class Solution {
    public int solution(int[] nums) {
        int answer = 0;
        HashSet<Integer> p = new HashSet();
        for(int i: nums){
            p.add(i);
        }
        int pick = nums.length / 2;
        if(pick >= p.size()) return p.size();
        
        return pick;
    }
}
```

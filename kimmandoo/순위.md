# 접근 방식
다익스트라로 접근했는데, 순위확정 아이디어가 정립이 안됐다...

순위를 확정하려면 level을 들고가야하나? 라고 생각했지만 모든 선수와의 관계를 알고있으면, 그건 순위가 확정된 것이고,

전이적으로도 승패가 결정나니까 플로이드 워셜을 써야함을 알 수 있었다.

# 풀이과정

지점 K를 '경유'해서 가는 경로와 기존의 경로를 비교하는 과정을 모든 K에 대해 반복
-> i에서 j로 바로 가는 기존의 최단 거리 vs i에서 k를 거쳐 j로 가는 새로운 거리

```
for k from 1 to N:  // '경유지'로 사용할 정점
  for i from 1 to N:  // '출발지' 정점
    for j from 1 to N:  // '도착지' 정점
      // i에서 j로 가는 기존 경로보다, k를 거쳐가는 경로가 더 짧다면 갱신
      dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
```

# 풀이코드

```java
class Solution {
    public int solution(int n, int[][] results) {
        boolean[][] canBeat = new boolean[n + 1][n + 1];

        for (int[] result : results) {
            int winner = result[0];
            int loser = result[1];
            canBeat[winner][loser] = true;
        }

        // 플로이드-워셜
        for (int k = 1; k <= n; k++) {
            for (int i = 1; i <= n; i++) {
                for (int j = 1; j <= n; j++) {
                    if (canBeat[i][k] && canBeat[k][j]) {
                        canBeat[i][j] = true;
                    }
                }
            }
        }

        int answer = 0;
        for (int i = 1; i <= n; i++) {
            int matchCount = 0;
            for (int j = 1; j <= n; j++) {
                if (i == j) continue;
                
                // i가 j를 이기거나, j가 i를 이기면(i가 j에게 지면) 경기 결과를 아는 것
                if (canBeat[i][j] || canBeat[j][i]) {
                    matchCount++;
                }
            }
            // 자신을 제외한 모든 선수(n-1)와의 승패를 알면 순위 확정 가능
            if (matchCount == n - 1) {
                answer++;
            }
        }

        return answer;
    }
}
```

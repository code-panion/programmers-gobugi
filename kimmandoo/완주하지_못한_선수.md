# 접근 방식

단 한명의 미 완주자를 찾는 것이고, 동명이인이 허용된다고 해서 set은 쓰지않고 list로 처리.
정렬시켜서 하나씩 돌다가 어긋나는 그 시점이 미완주자일 것.

# 학습 내용

String[]이라서 정렬 stl을 어떻게 사용해야하나 고민했다. 코테 감을 많이 잃어버린 게 맞음.
Collections 객체였으면 Collections.sort(p)로 해결 가능했는데, primitive 타입들을 포함한 Strings는 Arrays.sort를 써야한다.
내림차순 정렬, 커스텀 정렬까지 메모해야겠다.

```java
// 배열
Arrays.sort(arr, Comparator.reverseOrder()); // Comparable이 아닌 Comparator

// 리스트
Collections.sort(list, (a, b) -> b.length() - a.length()); 
List<String> list = Arrays.asList("a","aaa","aaaa");
list.sort((a, b) -> {
    if (a.length() != b.length()) return a.length() - b.length();
    return a.compareTo(b);
});
Collections.sort(list, new Comparator<String>() { // 이건 람다 안쓰는 방식, 익명 객체라고 해야하는지?
    public int compare(String a, String b) {
        return a.length() - b.length();
    }
});
```

평소에 kotlin을 쓰다보니 람다가 좀 더 편하다.

추가로 프로그래머스는 `java.util.*` 추가해줘야한다. 기본이 lang 밖에 안들어가 있는 것 같다.

# 풀이 코드

```java
import java.util.*;

class Solution {
    public String solution(String[] p, String[] c) {
        Arrays.sort(p);
        Arrays.sort(c);
        
        for(int i=0; i<c.length; i++){
            if(!p[i].equals(c[i])){
                return p[i];
            }
        }
        
        return p[c.length];
    }
}
```

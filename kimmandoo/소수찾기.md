# 접근 방식

소수를 미리 에라토스테네스 체로 만들고, 순열 돌려서 cnt를 늘리자고 생각했다.

# 학습 내용
```java
import java.util.*;

class Solution {
    boolean[] p;
    boolean[] v;
    int cnt = 0;
    HashSet<Integer> check;

    public int solution(String numbers) {
        erato(9999999);
        
        int len = numbers.length();
        v = new boolean[len];
        check = new HashSet();
        perm(0, len, numbers);
        
        return cnt;
    }
    
    public void perm(int idx, int n, String str){
        if(idx == n){
            StringBuilder sb = new StringBuilder();
            for(int i=0; i<n; i++){
                if(v[i]) sb.append(str.charAt(i));
            }
            int t = Integer.parseInt(sb.toString());
            if(p[t] && !check.contains(t)) {
                check.add(t);
                cnt++;
            }
            return;
        }
        for(int i=idx; i < n; i++){
            if(!v[i]){
                v[i] = true;
                perm(i+1, n, str);
                v[i] = false;
            }
        }
    }
    
    public void erato(int n) {
        p = new boolean[n + 1];
        Arrays.fill(p, true);
        p[0] = false; // 0도 일단 소수가 아니다
        p[1] = false; // 1도 소수가 아니다

        for (int i = 2; i * i <= n; i++) {
            if (p[i]) {
                for (int j = i * i; j <= n; j += i) {
                    p[j] = false;
                }
            }
        }
    }
}
```

순열을 만드는 부분이 제대로 구현되지않았던 게 크다.


# 풀이 코드 
```java
import java.util.*;

class Solution {
    boolean[] p;
    boolean[] v;
    int cnt = 0;
    HashSet<Integer> check;

    public int solution(String numbers) {
        erato(9999999);
        
        v = new boolean[len];
        check = new HashSet();
        // perm(0, len, numbers);
        perm("", numbers);
        
        return cnt;
    }
    
    public void perm(String currentNum, String numbers) {
        for (int i = 0; i < numbers.length(); i++) {
            if (!v[i]) {
                v[i] = true;
                
                String newNumStr = currentNum + numbers.charAt(i);
                int num = Integer.parseInt(newNumStr);
                
                if (p[num] && !check.contains(num)) {
                    cnt++;
                    check.add(num);
                }
                
                perm(newNumStr, numbers);
                
                v[i] = false;
            }
        }
    }
    
    public void erato(int n) {
        p = new boolean[n + 1];
        Arrays.fill(p, true);
        p[0] = false; // 0도 일단 소수가 아니다
        p[1] = false; // 1도 소수가 아니다

        for (int i = 2; i * i <= n; i++) {
            if (p[i]) {
                for (int j = i * i; j <= n; j += i) {
                    p[j] = false;
                }
            }
        }
    }
}
```

이렇게 하면, 자리수 상관 없이 모든 순열을 다 만들 게 된다.

근데 StringBuilder로 처리하는 게 더 이해하기가 편했다.

```java
public void perm(StringBuilder sb, char[] numbersArr) {
    for (int i = 0; i < numbersArr.length; i++) {
        if (!v[i]) {
            v[i] = true;
            sb.append(numbersArr[i]); // 문자 추가

            int num = Integer.parseInt(sb.toString());
            if (p[num] && !check.contains(num)) {
                cnt++;
                check.add(num);
            }

            perm(sb, numbersArr); // 다음 자릿수 조합을 위해 재귀

            // 백트래킹: 마지막에 추가했던 문자를 다시 제거
            sb.deleteCharAt(sb.length() - 1); 
            v[i] = false;
        }
    }
}
```

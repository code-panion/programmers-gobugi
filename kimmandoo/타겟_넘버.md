# 접근 방식

DFS로 풀었다. 적절히 더하고, 빼야하는데 보자마자 dfs가 생각났다.

# 학습 내용
오랜만에 푸니까, void 여도 base condition에 return을 넣어줘야한다는 사실을 잊고있었다...!

# 풀이 코드 

```java
class Solution {
    static int cnt = 0;
    
    public void dfs(int[] num, int idx, int sum, int t){
        if(idx == num.length){
            if(t == sum) cnt++;
            return;
        }
        dfs(num, idx+1, sum+num[idx], t); // +
        dfs(num, idx+1, sum-num[idx], t); // -
    }
    
    public int solution(int[] numbers, int target) {
        int answer = 0;
        // dfs
        dfs(numbers, 0, 0, target);
        
        return cnt;
    }
}
```

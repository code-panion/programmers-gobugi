# 접근 방식

그리디 문제인데 정렬문제에 더 가까운 것 같다.
앞 뒤로 1 차이나는 걸 찾아야하는데, 나는 앞에서 부터 훑는 방식을 선택했으니 무조건 sort를 해줘야한다. 이거 안해서 처음에 틀렸다.
먼저 여분 체육복이 있는데, 분실한 사람을 제거해야된다. 이 사람은 의미가 없다.
그리고 이걸 제거할 때, 방문배열을 꼭 만들어서 처리를 해준다.

이제 빌리는 로직을 짜야하는데,
빌리는 경우, 못빌리는 경우가 있다. 그래서 flag로 빌렸는 지, 못빌렸는 지 체크해서 못빌렸으면 참여학생수를 하나 줄여야한다. 처음부터 줄이고 시작해도 되는데, 로직을 더 이해하기 쉽게 만들기 위해서 이 방식을 선택헀다.

# 학습 내용

그리디는 왜 level 1도 어려울까

# 풀이 코드 

```java
import java.util.*;

class Solution {
    public int solution(int n, int[] l, int[] r) {
        Arrays.sort(l);
        Arrays.sort(r);
        boolean[] useR = new boolean[r.length];
        boolean[] useL = new boolean[l.length];

        // lost와 reserve에 모두 있는 사람 먼저 제외
        for (int i = 0; i < l.length; i++) {
            for (int j = 0; j < r.length; j++) {
                if (!useL[i] && !useR[j] && l[i] == r[j]) {
                    useL[i] = true;
                    useR[j] = true;
                    break;
                }
            }
        }

        int answer = n;
        
        // 빌릴 수 있는 경우 처리
        for (int i = 0; i < l.length; i++) {
            if (useL[i]) continue; // 이미 처리된 사람은 패스

            boolean borrowed = false;
            for (int j = 0; j < r.length; j++) {
                if (!useR[j] && Math.abs(l[i] - r[j]) == 1) {
                    useR[j] = true;
                    borrowed = true;
                    break;
                }
            }

            if (!borrowed) answer--; // 못 빌렸으면 체육복 없음
        }

        return answer;
    }
}
```

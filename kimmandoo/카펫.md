# 접근 방식

완탐문제는 자고로 관찰이 우선이라고 배웠다.

그림을 직접 그려보면서 문제를 정의했다. 우선 너비, 높이를 정의해야하는데, w+h는 brown값에서 각 귀퉁이 4칸을 뺀걸 /2 한것과 같다.
그리고 그게 안에 노란색 면적과 잘 호응하는 지 확인하면 되는 것이다.

문제는 넓이만 체크할 게 아니라, 전체 넓이를 w*h로 구할 수 있는 지도 체크해야한다. 
(w-2)*(h-2)만 확인하면 전체 넓이랑은 의미가 달라져서 다른 값을 도출한다.
yellow = (w-2)*(h-2) 조건을 만족하는 여러 (w,h) 조합이 존재할 수 있는데, 우린 전체 brown+yellow를 만족하는 걸 골라야한다!

# 풀이 코드 

```java
class Solution {
    public int[] solution(int brown, int yellow) {
        int[] answer = {};
        int wh = (brown+4)/2;
        // w >= h

        for(int w=wh; w > 2; w--){
            for(int h=2; h<=wh; h++){
                if((w-2)*(h-2) == yellow && w * h == brown + yellow) {
                    return new int[]{w,h};
                }
            }   
        }
        
        return answer;
    }
}
```

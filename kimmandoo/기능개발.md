# 접근 방식
우선 순위가 더 높은 작업이 끝나기 전에는 그 뒤의 작업이 빠지지않는다는 걸 보고, queue로 해결하려고했다.

```java
import java.util.*;

class Solution {
    public int[] solution(int[] progresses, int[] speeds) {        
        // 뒤에있는 기능이 먼저 완성돼도, 앞에꺼가 완성돼야 한번에 쫙 밀림
        // Queue로 해보자
        Queue<Integer> q = new LinkedList();
        ArrayList<Integer> res = new ArrayList();
        for(int i: progresses){
            q.offer(i);
        }
        
        int day = 1;
        while(!q.isEmpty()){
            int cnt = 0;
            for(int i=0; i < speeds.length; i++){
                int plus = day * speeds[i];
                if(q.peek() == progresses[i] && progresses[i] + plus >= 100){
                    q.poll();
                    cnt++;
                }
            }
            day++;
            if(cnt > 0){
                res.add(cnt);
            }
        }
        int[] arr = new int[res.size()];
        for (int i = 0; i < res.size(); i++) {
            arr[i] = res.get(i);
        }
        // System.out.println(res.toString());
        return arr;
    }
}
```

# 학습 내용

문제는 progress, speed를 같이 들고 다녀야 동기화 문제가 발생하지않는데, 나는 따로 들고다녀서 그런 것 같다.

추가로 ArrayList를 int[]로 변환하는 방법이 stream이 있지만, 그냥 일일이 넣는 게 건강에 좋다.

# 풀이 코드 
```java
import java.util.*;

class Solution {
    public int[] solution(int[] progresses, int[] speeds) {
        Queue<int[]> q = new LinkedList<>();
        ArrayList<Integer> res = new ArrayList<>();

        // progresses와 speeds를 묶어서 큐에 넣기
        for (int i = 0; i < progresses.length; i++) {
            q.offer(new int[]{progresses[i], speeds[i]});
        }

        while (!q.isEmpty()) {
            for (int[] t : q) {
                t[0] += t[1];
            }

            int cnt = 0;
            // 앞에서부터 완료된 기능만 묶어서 배포
            while (!q.isEmpty() && q.peek()[0] >= 100) {
                q.poll();
                cnt++;
            }

            if (cnt > 0) {
                res.add(cnt);
            }
        }

        int[] answer = new int[res.size()];
        for (int i = 0; i < res.size(); i++) {
            answer[i] = res.get(i);
        }

        return answer;
    }
}
```

# 접근 방식

그리디 너무 어렵다.
우선 타겟을 잡아야하는데, i번째 위치부터 끝나는 A지점을 찾고 그게 이제 되돌아오는 기준점이 된다.

# 학습 내용

오른쪽으로 가다가, 방향을 바꿔 왼쪽으로 이동 - 특정 지점까지 오른쪽으로 갔다가, 다시 왼쪽으로 돌아 남은 문자들을 처리하는 것이 더 효율적일 수 있으니
왼쪽으로 가다가, 방향을 바꿔 오른쪽으로 이동

# 풀이코드
```java
class Solution {
    public int solution(String name) {
        int answer = 0;
        int length = name.length();

        // 상하
        for (char c : name.toCharArray()) {
            answer += Math.min(c - 'A', 'Z' - c + 1);
        }

        // 좌우
        int minMove = length - 1;

        for (int i = 0; i < length; i++) {
            // i 다음부터 연속되는 'A'가 끝나는 지점 찾기
            int next = i + 1;
            while (next < length && name.charAt(next) == 'A') {
                next++;
            }

            // 오른쪽으로 갔다 되돌아오는 이동 vs 기존 최솟값
            // i * 2: 0 -> i -> 0 (오른쪽으로 갔다가 되돌아오는)
            // length - next: 남은 뒷부분을 처리하기 위해 왼쪽으로 가는
            int turnMove = (i * 2) + (length - next);
            minMove = Math.min(minMove, turnMove);
            
            // 왼쪽으로 갔다 되돌아오는 이동 vs 기존 최솟값
            // 대칭적인 경우도 고려
            int reverseTurnMove = (length - next) * 2 + i;
            minMove = Math.min(minMove, reverseTurnMove);
        }

        answer += minMove;
        return answer;
    }
}
```

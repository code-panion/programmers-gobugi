# 주식가격

## 🔍 문제에 접근한 방식과 이유
- 앞 가격 이상을 유지하는지 확인하고 미만일 경우 바로 break

### 오답 코드
```python
def solution(prices):
    answer = []
    # print(len(prices),"len(prices)")
    for i in range(len(prices)):
        time=0
        for j in range(i+1,len(prices)):
            if prices[i]<=prices[j]:
                # print(prices[i],prices[j],"i,j")
                time+=1
            else:
                # print(prices[i],prices[j],"i,j")
                time+=1
                break
        answer.append(time)
    # print(answer)
    return answer
```

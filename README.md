## 🤖고득점Kit 정복하기
- 문제집: https://school.programmers.co.kr/learn/challenges?tab=algorithm_practice_kit
- 진행 기간: `2025.07.01~2025.07.31`
- 진행 방식:
  - 고득점 Kit 47문제를 31일 동안 풀이
  - 문제 당 1천원으로 계산해서, 안 푼 문제 수 만큼 8월 1일 날 정산
  - 벌금으로 걷어진 금액은 사용처 고민
 
## 👽문제 풀이 업로드 규칙
- 본인의 닉네임 or 이름으로 브랜치를 생성
- 매주 일요일마다 pr올려서 main에 merge진행(코드리뷰를 별도로 진행하지 않지만, 코멘트 남기는 건 자유!)
- `/닉네임 or 이름/문제이름.md` (ex. `/kimmandoo/폰켓몬.md`)

## 👀마크다운 파일 규칙
- 파일명: `문제이름.md` (ex. 폰켓몬.md)
- 들어가야하는 내용
  - 문제에 접근한 방식과 이유
  - 오답인 경우 -> 오답이었던 이유
  - 정답인 경우 -> 로직에 대한 설명
  - 해설 보는 것도 자유, 그러나 해설을 봤으면 이해한 내용 기술 필수!
  - 오답/정답 코드(코드블럭)
